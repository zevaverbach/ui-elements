ui-elements

Components & live editor · Stable shell · Sanitizer test · Store test

Every component is loaded by relative path below. Serve this folder over http(s) (e.g. python3 -m http.server from the repo root, then open /demo/); ES modules do not load from file://. Speech needs a browser with the Web Speech API and a secure context.

Live editor

Edit the markup on the left; the dashed box on the right updates as you type, without a reload. Only ui-* components and plain layout tags work: scripts, on* handlers and javascript: URLs are stripped. The list below is bound to a <ui-store>, so ticking, editing, reordering and deleting update the store (shown underneath) and survive every edit of the markup. Give things you want to keep alive across edits a stable id.
